### О проекте
Primitive DB — это учебный проект, реализующий простую систему управления базой данных через командную строку. Проект создан для изучения современных практик разработки на Python, включая управление зависимостями через Poetry, линтинг с помощью Ruff и публикацию пакетов.

Проект демонстрирует:
Работу с файлами JSON для персистентного хранения
Парсинг и валидацию пользовательского ввода
Организацию кода в модули и пакеты
Автоматизацию задач с помощью Makefile
Контроль качества кода с помощью линтеров

### Возможности
Создание таблиц с указанием типов данных столбцов
Автоматическое добавление уникального ID-столбца
Просмотр списка существующих таблиц
Удаление таблиц
Персистентное хранение метаданных в JSON-файле
Интерактивный командный интерфейс с автодополнением
Валидация ввода и обработка ошибок
Поддержка типов данных: int, str, bool

### Использование
После запуска приложения вы увидите приветственное сообщение и доступные команды:

text
Первая попытка запустить проект!
***
<command> exit - выйти из программы
<command> help - справочная информация
Введите команду:
Основные команды
text
***База данных***
Функции:
<command> create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> .. - создать таблицу
<command> list_tables - показать список всех таблиц
<command> drop_table <имя_таблицы> - удалить таблицу
<command> exit - выход из программы
<command> help - справочная информация

Поддерживаемые типы данных
int — целые числа (например: 42, -15)
str — строки (например: "Hello", "Имя")
bool — логические значения (true/false)

Формат создания таблиц
text
create_table <имя_таблицы> <столбец:тип> <столбец:тип> ...
Пример:

text
create_table users name:str age:int is_active:bool
Примечание: Столбец ID:int добавляется автоматически в начало таблицы.

### Разработка
Требования
Python 3.12 или выше
Poetry 1.2.0 или выше
Git

Настройка окружения разработки
Установите Poetry:

bash
sudo apt install python3-poetry
poetry config virtualenvs.in-project true
Клонируйте и настройте проект:

bash
git clone <URL-репозитория>
cd project2_dorofeev_konstantin_m25-555
poetry install
Доступные команды Makefile
bash
make install          # Установка зависимостей
make project          # Запуск приложения через Poetry
make run              # Альтернативный запуск
make build            # Сборка пакета (wheel и tar.gz)
make publish          # Тест публикации (dry-run)
make package-install  # Установка пакета локально
make lint             # Проверка кода линтером (Ruff)
make clean            # Очистка временных файлов
Проверка качества кода
Проект использует Ruff для линтинга:

bash
Проверка всего проекта
make lint

Или напрямую через Poetry
poetry run ruff check .

Проверка с исправлением
poetry run ruff check . --fix
Тестирование публикации
bash

Сборка пакета
make build

Просмотр собранных файлов
ls -la dist/

Тест публикации (без реальной загрузки в PyPI)
make publish

💾 Хранение данных
Метаданные базы данных сохраняются в файл db_meta.json в формате JSON с поддержкой кириллицы и удобочитаемым форматированием.

Пример содержимого db_meta.json:

json
{
  "users": {
    "columns": [
      "ID:int",
      "name:str",
      "age:int",
      "is_active:bool"
    ]
  },
  "products": {
    "columns": [
      "ID:int",
      "title:str",
      "price:int",
      "in_stock:bool"
    ]
  }
}

Особенности хранения:
Автоматическое создание файла при первом запуске
Сохранение после каждой операции изменения данных
Поддержка UTF-8 кодировки
Читаемый формат с отступами
